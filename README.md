# Fundamentos da Programação - Exercícios e Atividades

Este repositório foi criado com o objetivo de reunir minhas resoluções dos exercícios e atividades desenvolvidos durante o curso de Fundamentos da Programação.

Além das atividades propostas no curso, também incluí exercícios extras sugeridos por mim, com foco em praticar lógica de programação, raciocínio computacional e reforçar os conteúdos estudados.

---

## Objetivo

Praticar conceitos essenciais da programação, como:

- Lógica de programação  
- Variáveis e tipos de dados  
- Operadores  
- Estruturas condicionais  
- Estruturas de repetição  
- Funções  
- Resolução de problemas  

---

## Organização

Os arquivos estão separados por temas, módulos ou listas de exercícios, facilitando a navegação e acompanhamento da evolução nos estudos.

- Linguagem Java
